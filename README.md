# Metro Ticket Generating System

## Project Overview
A ServiceNow-based Metro Ticket Generating System that allows users to select metro stations, calculate fares, and generate QR-based digital tickets.

## Features
- Metro station selection
- Single and return journey options
- Passenger count selection
- Automatic fare calculation
- Conditional payment-mode field visibility
- QR code containing journey details
- Order Confirmation and Checkout flow

## ServiceNow Components
- Metro Station's Details table
- Book A Metro Ticket catalog item
- Catalog variables
- Catalog Client Scripts
- Catalog UI Policy and UI Policy Action
- Metro QR Widget

## Technologies Used
- ServiceNow Service Portal
- Service Catalog
- Client Scripts
- UI Policies
- XML configuration exports

## Purpose
This project demonstrates a metro ticket booking workflow configured in ServiceNow, including fare calculation and QR-based journey information.

## Configuration
The exported ServiceNow XML configuration files will be added separately. They should be reviewed and tested in a suitable ServiceNow instance before importing.
